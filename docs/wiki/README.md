# Wiki 源页面

这个目录保存 MCBedrock-LegacyWindows GitHub Wiki 的源页面，文件名已经按 GitHub Wiki 约定整理。

当前 ChatGPT GitHub 连接不提供 Wiki 仓库写入接口，因此这些页面先保存在主仓库中，避免内容散失，也便于版本控制。

## 页面列表

- `Home.md`：Wiki 首页
- `_Sidebar.md`：Wiki 侧边栏
- `Client-Variants.md`：客户端与版本区别
- `Windows-7.md`：Windows 7 总指南
- `VxKex.md`：VxKex / VxKex NEXT 下载与使用
- `FeverGames-Downloader.md`：发烧游戏下载兼容
- `Windows-8.1.md`：Windows 8.1 总指南
- `Troubleshooting.md`：常见报错排查
- `FAQ.md`：常见问题
- `Release-and-Upgrade.md`：版本与升级

## 初始化 GitHub Wiki

仓库管理员可在 GitHub 仓库页面进入 **Wiki**，创建并保存第一张页面，使 Wiki 初始化。

之后这些 Markdown 页面可以原样作为 Wiki 页面内容使用，其中 `_Sidebar.md` 用作侧边导航，`Home.md` 用作首页。

正式 Wiki 建好后，主仓库 README 建议只保留一个醒目的 **Wiki / 详细说明** 入口，继续维持首页的快速导航定位。
