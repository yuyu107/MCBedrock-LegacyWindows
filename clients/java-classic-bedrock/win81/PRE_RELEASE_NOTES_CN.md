# Java 经典版内置基岩版 Windows 8.1 Launcher Bridge v1.0.0-RC1

> [!NOTE]
> 本页为**历史预发布说明**。当前正式方案已随 MCBedrock-LegacyWindows **v3.0.0** 发布，Java Classic 正式包版本为 **v1.0.1**，使用 Universal Bridge Core 0.4.3。
>
> 当前正式 Release：<https://github.com/yuyu107/MCBedrock-LegacyWindows/releases/tag/v3.0.0>

这是早期面向 **Windows 8.1 x64** 的 Release Candidate 记录。

## 当时已验证

- Minecraft.Windows.exe 1.21.120.0
- Java 经典版启动器正常启动
- 可进入游戏和世界
- 单人存档正常
- 非局域网联机正常

## 已知限制

- 本地 / 局域网联机目前不可用：无法加入同一局域网内其他玩家开放的本地房间，其他玩家也无法加入本机开放的本地房间。

## 历史说明

当时曾计划使用客户端专属 Tag：

```text
java-classic-win81-v1.0.0-rc1
```

项目后来改为统一的项目级 Release / Tag，因此不再使用该命名方案。当前源码与脚本仍位于 `clients/java-classic-bedrock/win81/`，本页仅保留历史记录。
